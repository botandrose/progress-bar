External CSS set on the <progress-bar> element

Properties applied to the host from the outside. The shadow DOM is sealed, so these affect the element's box and inherited properties, but not its internal track/fill structure.

DirectiveBehaviorResult
padding: 16px Host padding sits between the border and the content, filled with the track color (the fill stays inside .content). padding.xml
margin: 0 0 0 40px Normal outer margin; offsets the whole element. margin.xml
width: 200px Constrains the element width; fill percent is relative to it. width.xml
border: 3px dashed #c2185b Overrides the component's default 1px solid #999 host border (no CSS variable needed). border.xml
background: #9e9e9e Sets the unfilled track color — it's just the host background; the fill (.bar) sits on top. background.xml
border-radius: 16px Rounds the host; the fill is clipped to match because the host sets overflow: hidden. radius.xml
box-shadow: 0 2px 8px rgba(0,0,0,.5) Applies to the host box; the component never sets its own shadow. shadow.xml
opacity: 0.4 Fades the entire element, identical to the consumer .pending class. opacity.xml
transform: scale(1.1) rotate(-2deg) Transforms the host box as a unit, fill and text included. transform.xml
font-size: 20px No effect on the label: .content sets its own font-size: 13px inside the shadow root, which wins for slotted text. font-size.xml

CSS variables & their effects

Custom properties on the host. These exist only for things a plain CSS directive can't reach — the sealed shadow internals (the fill and the inner label). Host-level styling (background, border, radius) is done with standard CSS, shown in the table above. Each row overrides one variable to a dramatic value so the effect is visible.

VariableDefault & effectOverride
--progress-color #2E7D32 — the fill color. #1565c0
--error-color #7a242f — the fill color when the host has class error. #ff7043 (.error)
--bar-padding 8px — padding around the label inside the fill area. 18px
--bar-height 32px — minimum height of the bar; label is vertically centered. 64px
--progress-duration 120ms — width transition time (drive the slider below to feel it). 1500ms

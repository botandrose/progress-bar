Indeterminate (the default — no percent set)

A <progress-bar> with no percent attribute (or percent = null) is indeterminate: the fill sweeps (linear) or the arc spins (circular) and aria-valuenow is dropped. Set a numeric percent to make it determinate.

External CSS set on the <progress-bar> element

Properties applied to the host from the outside. The shadow DOM is sealed, so these affect the element's box and inherited properties, but not its internal track/fill structure.

DirectiveBehaviorResult
padding: 16px Host padding insets the slotted label; the host paints the track behind it and the fill (.bar) still spans the full inner box. padding.xml
margin: 0 0 0 40px Normal outer margin; offsets the whole element. margin.xml
width: 200px Constrains the element width; fill percent is relative to it. width.xml
border: 3px dashed #c2185b Overrides the component's default 1px solid #999 host border (no CSS variable needed). border.xml
background: #9e9e9e Sets the unfilled track color — it's just the host background; the fill (.bar) sits on top. background.xml
border-radius: 16px Rounds the host; the fill is clipped to match because the host sets overflow: hidden. radius.xml
box-shadow: 0 2px 8px rgba(0,0,0,.5) Applies to the host box; the component never sets its own shadow. shadow.xml
opacity: 0.4 Fades the entire element — a consumer can use it to mark, say, a disabled or superseded item. opacity.xml
transform: scale(1.1) rotate(-2deg) Transforms the host box as a unit, fill and text included. transform.xml
font-size: 20px Enlarges the label: the host sets font-size: 13px and the slotted text inherits it, so an outside font-size wins. font-size.xml

External CSS on the circular variant

Circular mode resets the host box — it sets background: transparent, border: none, and overflow: visible — so the same directives behave differently than on the linear bar. The ring's diameter is fixed by --circular-size, not the host width. Inline styles still win over the mode reset.

DirectiveBehaviorResult
background: #9e9e9e Circular mode makes the host transparent; setting a background paints a box behind the ring (the track is the SVG circle, not the host). 60%
border: 3px dashed #c2185b Circular mode drops the host border; you can still add one — it frames the ring's box rather than the ring itself. 60%
padding: 16px Adds space inside the host box, offsetting the ring down and to the right. 60%
width: 200px Widens the host box but not the ring — diameter is set by --circular-size. The ring stays its size, left-aligned. 60%
border-radius: 16px; background:#9e9e9e Rounds the host box (only visible once a background or border is set, since the box is otherwise transparent). 60%
box-shadow: 0 2px 8px rgba(0,0,0,.5) Applies to the host box, so the shadow traces the rectangular box, not the circle. 60%
transform: scale(1.1) rotate(-10deg) Transforms the whole element as a unit — ring and label together. 60%
opacity: 0.4 Fades the entire element — a consumer can use it to mark, say, a disabled or superseded item. 60%
color: #1565c0 The label inherits the host color (.label uses color: inherit), so the centered text picks this up. 60%
font-size: 20px No effect on the label: .label sets its own font-size: 13px inside the shadow root. 60%

CSS variables & their effects

Custom properties on the host. These exist only for things a plain CSS directive can't reach — the sealed shadow internals (the fill and the inner label). Host-level styling (background, border, radius) is done with standard CSS, shown in the table above. Each row overrides one variable to a dramatic value so the effect is visible.

VariableDefault & effectOverride
--progress-color #2E7D32 — the fill color. #1565c0
--error-color #7a242f — the fill color when the host has the error attribute. #ff7043 ([error])
--bar-padding 8px — padding around the label inside the fill area. 18px
--bar-height 32px — minimum height of the bar; label is vertically centered. 64px
--progress-duration 120ms — width transition time (drive the slider below to feel it). 1500ms
